
# Personal Expense Tracker

## Project Overview
Personal Expense Tracker is a beginner-level Python application
that helps users record, manage, search, and analyze daily expenses.

## Features
- Add a new expense
- View all expenses
- Search expenses by category
- Calculate total expenses
- Display monthly expense summary
- Delete an expense
- Save data using JSON
- Validate user input and handle common errors

## Technologies Used
- Python
- JSON
- VS Code
- Git and GitHub

## Project Structure
Personal_Expense_Tracker/
├── main.py

└── screenshots/

## How to Run the Project

1. Install Python on your computer.
2. Open this project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python main.py

5. Select an option from the menu.
6. Follow the instructions displayed on the screen.

## Data Storage
Expense records are stored in expenses.json.
The records remain saved after the application is closed.
